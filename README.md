# Perkata Berwarna · AtTartil Quranic Institute

Colour-coded word-by-word Qur'an notes (isim green, fi'il yellow, harf red) with BM/EN toggle, root letters and the fā'il of every verb.

- `index.html` — home page
- `al-fatihah/` — Surah al-Fatihah (7 ayat)
- `al-baqarah/` — Surah al-Baqarah (bahagian 1: ayat 1–20; bahagian 2 di `al-baqarah/21-39/`: ayat 21–39; bahagian 3–6 di `al-baqarah/40-74/`, `75-103/`, `104-123/`, `124-141/`; 12 bahagian dirancang)
- `al-kahfi/` — Surah al-Kahfi (110 ayat)
- `yasin/` — Surah Yasin (83 ayat)
- `ar-rahman/` — Surah ar-Rahman (78 ayat)
- `al-waqiah/` — Surah al-Waqi‘ah (96 ayat)
- `al-mulk/` — Surah al-Mulk (30 ayat)
- `at-takathur/` … `al-masad/` — Surah 102–111 (at-Takathur, al-‘Asr, al-Humazah, al-Fil, Quraisy, al-Ma‘un, al-Kauthar, al-Kafirun, an-Nasr, al-Masad)
- `al-ikhlas/`, `al-falaq/`, `an-nas/` — Surah al-Ikhlas, al-Falaq, an-Nas
- `3-qul/` — link page with only the last 3 surahs (al-Ikhlas, al-Falaq, an-Nas)

Static site, no build step. Every push to `main` deploys on Vercel.

Verse translations: Tafsir Pimpinan ar-Rahman (Basmeih); English: AtTartil's own translation following Basmeih.
